Your assistant turns a question into one tool call. Each call below is the exact tool and arguments
for a common question. The repository checks each one against the tool's input schema. The dates and
identifiers are made up: your assistant fills in values that fit the question.

## Check a set-aside code

"What does set-aside code 8AN mean?" Ask this before you filter on a code. `8A` is 8(a) Competed
and `8AN` is 8(a) Sole Source. This needs no key.

## Tips

- **Filter first.** Each source has its own quota, and some are small. One well-filtered call is
  better than many lookups.
- **Read `filters` and `warnings`.** They say which filters the source applied and which the server
  applied to one page. A `total` of `null` means the count cannot be trusted.
- **Check codes before using them.** `lookup_reference_code` lists the codes of a domain.
- **Start with a small `limit`**, and on tools that return a `next_cursor`, pass it back as `cursor`
  for more. The SAM.gov searches, the exclusion check and the Tango protest, IDV, vehicle and OTA
  searches have no cursor: narrow their filters instead.
- **Use `aggregate_contracts` for population figures.** `get_tango_spending_summary` summarizes one
  page of at most 100 records, and says when there are more.
